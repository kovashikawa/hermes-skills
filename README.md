# Hermes skills

Open skills developed from working projects with Hermes Agent.

## markdown-to-manim-video

Turn a technical Markdown document and its runnable code into a source-grounded Manim explainer with deterministic data, LaTeX, frame-level verification, and independent review.

### Hermes

```bash
hermes skills install kovashikawa/hermes-skills/markdown-to-manim-video
```

Or add the repository as a tap:

```bash
hermes skills tap add kovashikawa/hermes-skills
hermes skills search manim
```

### Other agents

The skill follows the open `SKILL.md` format used by agentskills.codes. Copy or install `skills/markdown-to-manim-video/SKILL.md` into the skills directory supported by your agent.
